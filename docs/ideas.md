# BatyaOS — банк идей

Здесь хранятся возможные улучшения продукта.

Идея не является обязательством к реализации.
Добавление идеи не меняет текущий план разработки.

## Правила

- Быстро фиксируем мысли, не требуя подробного описания.
- Каждая идея получает постоянный номер IDEA-001, IDEA-002 и далее.
- Перед реализацией отдельно обсуждаем пользу и объём работы.
- Похожие идеи объединяем, сохраняя ссылки на их номера.
- Неактуальные идеи отправляем в архив с короткой причиной.
- Ранее предложенные функции не считаются одобренными автоматически.

## Статусы

- Входящие
- На рассмотрении
- В плане
- Реализовано
- Архив

## Идеи

### IDEA-001

Приложение помогает отслеживать действия в разных сферах жизни:

Fitness — тренировка, прогулка, количество шагов, растяжка.

Music — занятия на гитаре, выученные песни, минуты практики.

Career — отправленные резюме, отклики, подготовленные ответы.

Learning — прочитанные страницы, изученные темы, часы обучения.

Personal — сон, медитация, домашние задачи.

Finance — экономия денег, контроль расходов.

Projects — прогресс по личным и профессиональным проектам.

Главная идея: пользователь не отмечает абстрактную привычку «быть продуктивным», а фиксирует конкретный результат — например, «30 минут играл на гитаре» или «отправил 3 резюме».

### IDEA-002

Каждая запись может иметь такие поля:

сфера;
название действия;
дата;
числовое значение;
единица измерения — минуты, штуки, километры, страницы;
комментарий;
выполнена ли цель.

### IDEA-003

Я бы не ограничивал приложение только привычками. Можно сделать три типа целей:

Тип-Пример-Как считать
Да/нет-Сделать тренировку-Выполнено или нет
Количество-Отправить 5 резюме-Фактическое число против цели
Время-Играть на гитаре 30 минут-Минуты против недельной цели

### IDEA-004

Dashboard
Обзор текущего дня или недели:

выполненные цели;

прогресс по сферам;

текущие серии;

самые активные направления;

цели, которыми давно не занимался.

### IDEA-005

Добавление активности
Быстрая форма:

выбрать сферу;

выбрать действие;

указать результат;

добавить заметку;

сохранить одним нажатием.

### IDEA-006

Статистика
Показывать:

прогресс за неделю;

сравнение недель;

количество действий по каждой сфере;

наиболее стабильные направления;

пропущенные дни;

суммарное время.

### IDEA-007

функция для портфолио — еженедельный отчёт:

text
Твоя неделя

Лучший результат: Career
Слабое направление: Music
Совет: запланировать гитару на вторник и четверг

### IDEA-008

MVP:

Создание сфер.

Создание целей.

Добавление ежедневного результата.

Экран текущего дня.

Недельная статистика.

Сохранение данных локально.

Редактирование и удаление записей.

### IDEA-009

Что можно добавить позже
После MVP проект можно развивать:

напоминания;

календарь;

виджет;

импорт данных;

iCloud-синхронизацию;

экспорт в CSV;

режим «только карьерный прогресс»;

AI-анализ недели;

цели с дедлайнами;

оценку энергии и настроения;

совместное использование с коучем или наставником.

### IDEA-010

В desktop-версии особенно полезны:

боковая панель со сферами;

большая рабочая область со статистикой;

быстрые клавиатурные команды;

системные уведомления;

отдельное окно или popup для быстрого добавления активности;

экспорт данных в CSV или JSON.

Например, сочетание Cmd/Ctrl + K может открывать командное меню:

text
Add activity
View weekly report
Create goal
Export data
Open settings
Это сразу делает проект более похожим на настоящий desktop-инструмент, а не просто на сайт в отдельном окне.
